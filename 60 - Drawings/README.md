# 60 - Drawings

Папка для рисунков Excalidraw (в настройках плагина Excalidraw уже указан путь `60 - Drawings`).
Если нужен «нарисованный вручную» вариант графа: `Ctrl+P → Excalidraw: Create new drawing`,
а структуру можно перенести из экспорта **Lecture Graph** (команды `Export current graph as SVG`
и `Export labels + reference counts (CSV)` → файлы в `90 - Exports/`).
