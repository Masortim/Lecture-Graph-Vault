# Gradient Descent Example 3.4.5d

**梯度下降例子 3.4.5d** · example · 3.4.5d

⬆️ Part of [[Ch03-S04-H05 - Main Theorem Gradient Descent|Main Theorem: Gradient Descent]] · [[Ch03-S04-H05 - Main Theorem Gradient Descent|梯度下降：主定理]]

The model case below shows that the hypothesis cannot be dropped:

$$
T e_k \;=\; \lambda_k e_k, \qquad
\sum_{k=1}^{\infty} |\lambda_k| \;<\; \infty,
 \qquad \lVert T \rVert_{\mathrm{tr}} = \sum_{k} |\lambda_k|.
$$

去掉条件后结论不再成立。
