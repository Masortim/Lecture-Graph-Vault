# Gradient Descent Identity 3.4.5b

**梯度下降恒等式 3.4.5b** · identity · 3.4.5b

⬆️ Part of [[Ch03-S04-H05 - Main Theorem Gradient Descent|Main Theorem: Gradient Descent]] · [[Ch03-S04-H05 - Main Theorem Gradient Descent|梯度下降：主定理]]

The pairing is computed in coordinates, which gives the identity we quote later:

$$
\langle x, y \rangle \;=\; \sum_{i=1}^{n} x_i \overline{y_i}
 \;=\; \lVert P_{M} x \rVert^{2} + \lVert P_{M^{\perp}} x \rVert^{2}.
$$

恒等式在正交投影的讨论中反复使用。
