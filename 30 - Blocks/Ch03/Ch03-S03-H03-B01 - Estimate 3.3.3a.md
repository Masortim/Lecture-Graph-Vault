# Hahn-Banach Extension Estimate 3.3.3a

**哈恩-巴拿赫延拓估计 3.3.3a** · estimate · 3.3.3a

⬆️ Part of [[Ch03-S03-H03 - Basic Properties Hahn-Banach Extension|Basic Properties: Hahn-Banach Extension]] · [[Ch03-S03-H03 - Basic Properties Hahn-Banach Extension|哈恩-巴拿赫延拓：基本性质]]

A standard symmetrisation argument yields the quantitative bound:

$$
\mathbb{P}\bigl\{\,|f(X)-\mathbb{E}f| \ge t\,\bigr\}
 \;\le\; 2\exp\!\left(-\frac{2nt^{2}}{(b-a)^{2}}\right),
 \qquad t>0.
$$

此估计决定了样本复杂度的阶。
