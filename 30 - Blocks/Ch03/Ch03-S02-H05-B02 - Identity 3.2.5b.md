# Singular Values Identity 3.2.5b

**奇异值恒等式 3.2.5b** · identity · 3.2.5b

⬆️ Part of [[Ch03-S02-H05 - Main Theorem Singular Values|Main Theorem: Singular Values]] · [[Ch03-S02-H05 - Main Theorem Singular Values|奇异值：主定理]]

The pairing is computed in coordinates, which gives the identity we quote later:

$$
\langle x, y \rangle \;=\; \sum_{i=1}^{n} x_i \overline{y_i}
 \;=\; \lVert P_{M} x \rVert^{2} + \lVert P_{M^{\perp}} x \rVert^{2}.
$$

恒等式在正交投影的讨论中反复使用。
