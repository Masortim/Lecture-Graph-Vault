# Gradient Descent Proposition 3.4.5a

**梯度下降命题 3.4.5a** · statement · 3.4.5a

⬆️ Part of [[Ch03-S04-H05 - Main Theorem Gradient Descent|Main Theorem: Gradient Descent]] · [[Ch03-S04-H05 - Main Theorem Gradient Descent|梯度下降：主定理]]

For every $x \in X$ the quantity below is finite and controls the rest of the section:

$$
\lVert Tx \rVert \;\le\; L\,\lVert x \rVert_{X}, \qquad L = \sup_{\lVert x \rVert_{X}=1} \lVert Tx \rVert_{Y}.
$$

该命题是本节后续结果的出发点。
