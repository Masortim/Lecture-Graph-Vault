# Hahn-Banach Extension Identity 8.3.3d

**哈恩-巴拿赫延拓恒等式 8.3.3d** · identity · 8.3.3d

⬆️ Part of [[Ch08-S03-H03 - Basic Properties Hahn-Banach Extension|Basic Properties: Hahn-Banach Extension]] · [[Ch08-S03-H03 - Basic Properties Hahn-Banach Extension|哈恩-巴拿赫延拓：基本性质]]

The pairing is computed in coordinates, which gives the identity we quote later:

$$
\langle x, y \rangle \;=\; \sum_{i=1}^{n} x_i \overline{y_i}
 \;=\; \lVert P_{M} x \rVert^{2} + \lVert P_{M^{\perp}} x \rVert^{2}.
$$

恒等式在正交投影的讨论中反复使用。
