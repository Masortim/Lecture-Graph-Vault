# Gradient Descent Example 8.4.5d

**梯度下降例子 8.4.5d** · example · 8.4.5d

⬆️ Part of [[Ch08-S04-H05 - Main Theorem Gradient Descent|Main Theorem: Gradient Descent]] · [[Ch08-S04-H05 - Main Theorem Gradient Descent|梯度下降：主定理]]

The model case below shows that the hypothesis cannot be dropped:

$$
T e_k \;=\; \lambda_k e_k, \qquad
\sum_{k=1}^{\infty} |\lambda_k| \;<\; \infty,
 \qquad \lVert T \rVert_{\mathrm{tr}} = \sum_{k} |\lambda_k|.
$$

去掉条件后结论不再成立。

Used together with: [[Ch02-S04-H05-B02 - Identity 2.4.5b|Identity 2.4.5b]], [[Ch04-S01-H04-B01 - Example 4.1.4a|Example 4.1.4a]].
