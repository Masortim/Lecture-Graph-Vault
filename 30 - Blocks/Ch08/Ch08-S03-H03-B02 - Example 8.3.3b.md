# Hahn-Banach Extension Example 8.3.3b

**哈恩-巴拿赫延拓例子 8.3.3b** · example · 8.3.3b

⬆️ Part of [[Ch08-S03-H03 - Basic Properties Hahn-Banach Extension|Basic Properties: Hahn-Banach Extension]] · [[Ch08-S03-H03 - Basic Properties Hahn-Banach Extension|哈恩-巴拿赫延拓：基本性质]]

The model case below shows that the hypothesis cannot be dropped:

$$
T e_k \;=\; \lambda_k e_k, \qquad
\sum_{k=1}^{\infty} |\lambda_k| \;<\; \infty,
 \qquad \lVert T \rVert_{\mathrm{tr}} = \sum_{k} |\lambda_k|.
$$

去掉条件后结论不再成立。
