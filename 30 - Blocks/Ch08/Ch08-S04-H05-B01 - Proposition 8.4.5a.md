# Gradient Descent Proposition 8.4.5a

**梯度下降命题 8.4.5a** · statement · 8.4.5a

⬆️ Part of [[Ch08-S04-H05 - Main Theorem Gradient Descent|Main Theorem: Gradient Descent]] · [[Ch08-S04-H05 - Main Theorem Gradient Descent|梯度下降：主定理]]

For every $x \in X$ the quantity below is finite and controls the rest of the section:

$$
\lVert Tx \rVert \;\le\; L\,\lVert x \rVert_{X}, \qquad L = \sup_{\lVert x \rVert_{X}=1} \lVert Tx \rVert_{Y}.
$$

该命题是本节后续结果的出发点。

Used together with: [[Ch02-S03-H05-B02 - Identity 2.3.5b|Identity 2.3.5b]], [[Ch03-S04-H04-B01 - Example 3.4.4a|Example 3.4.4a]].
