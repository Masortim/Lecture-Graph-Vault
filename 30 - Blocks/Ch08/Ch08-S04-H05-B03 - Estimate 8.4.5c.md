# Gradient Descent Estimate 8.4.5c

**梯度下降估计 8.4.5c** · estimate · 8.4.5c

⬆️ Part of [[Ch08-S04-H05 - Main Theorem Gradient Descent|Main Theorem: Gradient Descent]] · [[Ch08-S04-H05 - Main Theorem Gradient Descent|梯度下降：主定理]]

A standard symmetrisation argument yields the quantitative bound:

$$
\mathbb{P}\bigl\{\,|f(X)-\mathbb{E}f| \ge t\,\bigr\}
 \;\le\; 2\exp\!\left(-\frac{2nt^{2}}{(b-a)^{2}}\right),
 \qquad t>0.
$$

此估计决定了样本复杂度的阶。

Used together with: [[Ch02-S04-H03-B02 - Example 2.4.3b|Example 2.4.3b]], [[Ch04-S01-H02-B01 - Identity 4.1.2a|Identity 4.1.2a]].
