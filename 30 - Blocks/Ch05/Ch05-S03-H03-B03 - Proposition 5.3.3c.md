# Gradient Descent Proposition 5.3.3c

**梯度下降命题 5.3.3c** · statement · 5.3.3c

⬆️ Part of [[Ch05-S03-H03 - Basic Properties Gradient Descent|Basic Properties: Gradient Descent]] · [[Ch05-S03-H03 - Basic Properties Gradient Descent|梯度下降：基本性质]]

For every $x \in X$ the quantity below is finite and controls the rest of the section:

$$
\lVert Tx \rVert \;\le\; L\,\lVert x \rVert_{X}, \qquad L = \sup_{\lVert x \rVert_{X}=1} \lVert Tx \rVert_{Y}.
$$

该命题是本节后续结果的出发点。
