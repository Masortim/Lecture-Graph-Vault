# Gradient Descent Identity 5.3.3d

**梯度下降恒等式 5.3.3d** · identity · 5.3.3d

⬆️ Part of [[Ch05-S03-H03 - Basic Properties Gradient Descent|Basic Properties: Gradient Descent]] · [[Ch05-S03-H03 - Basic Properties Gradient Descent|梯度下降：基本性质]]

The pairing is computed in coordinates, which gives the identity we quote later:

$$
\langle x, y \rangle \;=\; \sum_{i=1}^{n} x_i \overline{y_i}
 \;=\; \lVert P_{M} x \rVert^{2} + \lVert P_{M^{\perp}} x \rVert^{2}.
$$

恒等式在正交投影的讨论中反复使用。
