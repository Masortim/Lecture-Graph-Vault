# Gradient Descent Example 5.3.3b

**梯度下降例子 5.3.3b** · example · 5.3.3b

⬆️ Part of [[Ch05-S03-H03 - Basic Properties Gradient Descent|Basic Properties: Gradient Descent]] · [[Ch05-S03-H03 - Basic Properties Gradient Descent|梯度下降：基本性质]]

The model case below shows that the hypothesis cannot be dropped:

$$
T e_k \;=\; \lambda_k e_k, \qquad
\sum_{k=1}^{\infty} |\lambda_k| \;<\; \infty,
 \qquad \lVert T \rVert_{\mathrm{tr}} = \sum_{k} |\lambda_k|.
$$

去掉条件后结论不再成立。
