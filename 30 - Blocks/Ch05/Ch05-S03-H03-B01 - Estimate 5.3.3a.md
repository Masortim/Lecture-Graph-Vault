# Gradient Descent Estimate 5.3.3a

**梯度下降估计 5.3.3a** · estimate · 5.3.3a

⬆️ Part of [[Ch05-S03-H03 - Basic Properties Gradient Descent|Basic Properties: Gradient Descent]] · [[Ch05-S03-H03 - Basic Properties Gradient Descent|梯度下降：基本性质]]

A standard symmetrisation argument yields the quantitative bound:

$$
\mathbb{P}\bigl\{\,|f(X)-\mathbb{E}f| \ge t\,\bigr\}
 \;\le\; 2\exp\!\left(-\frac{2nt^{2}}{(b-a)^{2}}\right),
 \qquad t>0.
$$

此估计决定了样本复杂度的阶。
