# Feature Map Estimate 9.1.3a

**特征映射估计 9.1.3a** · estimate · 9.1.3a

⬆️ Part of [[Ch09-S01-H03 - Basic Properties Feature Map|Basic Properties: Feature Map]] · [[Ch09-S01-H03 - Basic Properties Feature Map|特征映射：基本性质]]

A standard symmetrisation argument yields the quantitative bound:

$$
\mathbb{P}\bigl\{\,|f(X)-\mathbb{E}f| \ge t\,\bigr\}
 \;\le\; 2\exp\!\left(-\frac{2nt^{2}}{(b-a)^{2}}\right),
 \qquad t>0.
$$

此估计决定了样本复杂度的阶。
