# Vector Space Example 9.2.3b

**向量空间例子 9.2.3b** · example · 9.2.3b

⬆️ Part of [[Ch09-S02-H03 - Basic Properties Vector Space|Basic Properties: Vector Space]] · [[Ch09-S02-H03 - Basic Properties Vector Space|向量空间：基本性质]]

The model case below shows that the hypothesis cannot be dropped:

$$
T e_k \;=\; \lambda_k e_k, \qquad
\sum_{k=1}^{\infty} |\lambda_k| \;<\; \infty,
 \qquad \lVert T \rVert_{\mathrm{tr}} = \sum_{k} |\lambda_k|.
$$

去掉条件后结论不再成立。

Used together with: [[Ch05-S03-H03-B03 - Proposition 5.3.3c|Proposition 5.3.3c]], [[Ch06-S04-H02-B02 - Estimate 6.4.2b|Estimate 6.4.2b]].
