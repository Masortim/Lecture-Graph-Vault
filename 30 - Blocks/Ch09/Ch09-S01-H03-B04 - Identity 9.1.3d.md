# Feature Map Identity 9.1.3d

**特征映射恒等式 9.1.3d** · identity · 9.1.3d

⬆️ Part of [[Ch09-S01-H03 - Basic Properties Feature Map|Basic Properties: Feature Map]] · [[Ch09-S01-H03 - Basic Properties Feature Map|特征映射：基本性质]]

The pairing is computed in coordinates, which gives the identity we quote later:

$$
\langle x, y \rangle \;=\; \sum_{i=1}^{n} x_i \overline{y_i}
 \;=\; \lVert P_{M} x \rVert^{2} + \lVert P_{M^{\perp}} x \rVert^{2}.
$$

恒等式在正交投影的讨论中反复使用。
