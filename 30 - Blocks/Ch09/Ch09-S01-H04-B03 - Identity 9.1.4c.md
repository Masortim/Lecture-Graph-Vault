# Kernel Matrix Identity 9.1.4c

**核矩阵恒等式 9.1.4c** · identity · 9.1.4c

⬆️ Part of [[Ch09-S01-H04 - Key Lemma Kernel Matrix|Key Lemma: Kernel Matrix]] · [[Ch09-S01-H04 - Key Lemma Kernel Matrix|核矩阵：关键引理]]

The pairing is computed in coordinates, which gives the identity we quote later:

$$
\langle x, y \rangle \;=\; \sum_{i=1}^{n} x_i \overline{y_i}
 \;=\; \lVert P_{M} x \rVert^{2} + \lVert P_{M^{\perp}} x \rVert^{2}.
$$

恒等式在正交投影的讨论中反复使用。
