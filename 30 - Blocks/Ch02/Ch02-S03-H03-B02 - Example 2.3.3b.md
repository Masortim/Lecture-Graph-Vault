# Spectral Gap Example 2.3.3b

**谱隙例子 2.3.3b** · example · 2.3.3b

⬆️ Part of [[Ch02-S03-H03 - Basic Properties Spectral Gap|Basic Properties: Spectral Gap]] · [[Ch02-S03-H03 - Basic Properties Spectral Gap|谱隙：基本性质]]

The model case below shows that the hypothesis cannot be dropped:

$$
T e_k \;=\; \lambda_k e_k, \qquad
\sum_{k=1}^{\infty} |\lambda_k| \;<\; \infty,
 \qquad \lVert T \rVert_{\mathrm{tr}} = \sum_{k} |\lambda_k|.
$$

去掉条件后结论不再成立。

Used together with: [[Ch03-S02-H04-B02 - Proposition 3.2.4b|Proposition 3.2.4b]], [[Ch04-S03-H03-B02 - Example 4.3.3b|Example 4.3.3b]].
