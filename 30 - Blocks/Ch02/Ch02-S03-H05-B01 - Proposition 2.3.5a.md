# Vector Space Proposition 2.3.5a

**向量空间命题 2.3.5a** · statement · 2.3.5a

⬆️ Part of [[Ch02-S03-H05 - Main Theorem Vector Space|Main Theorem: Vector Space]] · [[Ch02-S03-H05 - Main Theorem Vector Space|向量空间：主定理]]

For every $x \in X$ the quantity below is finite and controls the rest of the section:

$$
\lVert Tx \rVert \;\le\; L\,\lVert x \rVert_{X}, \qquad L = \sup_{\lVert x \rVert_{X}=1} \lVert Tx \rVert_{Y}.
$$

该命题是本节后续结果的出发点。
