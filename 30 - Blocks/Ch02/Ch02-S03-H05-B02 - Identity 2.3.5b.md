# Vector Space Identity 2.3.5b

**向量空间恒等式 2.3.5b** · identity · 2.3.5b

⬆️ Part of [[Ch02-S03-H05 - Main Theorem Vector Space|Main Theorem: Vector Space]] · [[Ch02-S03-H05 - Main Theorem Vector Space|向量空间：主定理]]

The pairing is computed in coordinates, which gives the identity we quote later:

$$
\langle x, y \rangle \;=\; \sum_{i=1}^{n} x_i \overline{y_i}
 \;=\; \lVert P_{M} x \rVert^{2} + \lVert P_{M^{\perp}} x \rVert^{2}.
$$

恒等式在正交投影的讨论中反复使用。
