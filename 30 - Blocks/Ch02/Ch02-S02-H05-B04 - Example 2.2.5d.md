# Feature Map Example 2.2.5d

**特征映射例子 2.2.5d** · example · 2.2.5d

⬆️ Part of [[Ch02-S02-H05 - Main Theorem Feature Map|Main Theorem: Feature Map]] · [[Ch02-S02-H05 - Main Theorem Feature Map|特征映射：主定理]]

The model case below shows that the hypothesis cannot be dropped:

$$
T e_k \;=\; \lambda_k e_k, \qquad
\sum_{k=1}^{\infty} |\lambda_k| \;<\; \infty,
 \qquad \lVert T \rVert_{\mathrm{tr}} = \sum_{k} |\lambda_k|.
$$

去掉条件后结论不再成立。

Used together with: [[Ch02-S02-H03-B03 - Proposition 2.2.3c|Proposition 2.2.3c]], [[Ch03-S03-H02-B02 - Estimate 3.3.2b|Estimate 3.3.2b]].
