# Orthogonal Projection Example 7.4.3b

**正交投影例子 7.4.3b** · example · 7.4.3b

⬆️ Part of [[Ch07-S04-H03 - Basic Properties Orthogonal Projection|Basic Properties: Orthogonal Projection]] · [[Ch07-S04-H03 - Basic Properties Orthogonal Projection|正交投影：基本性质]]

The model case below shows that the hypothesis cannot be dropped:

$$
T e_k \;=\; \lambda_k e_k, \qquad
\sum_{k=1}^{\infty} |\lambda_k| \;<\; \infty,
 \qquad \lVert T \rVert_{\mathrm{tr}} = \sum_{k} |\lambda_k|.
$$

去掉条件后结论不再成立。
