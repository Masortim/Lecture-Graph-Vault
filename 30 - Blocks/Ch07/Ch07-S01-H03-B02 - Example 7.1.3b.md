# Approximation Error Example 7.1.3b

**逼近误差例子 7.1.3b** · example · 7.1.3b

⬆️ Part of [[Ch07-S01-H03 - Basic Properties Approximation Error|Basic Properties: Approximation Error]] · [[Ch07-S01-H03 - Basic Properties Approximation Error|逼近误差：基本性质]]

The model case below shows that the hypothesis cannot be dropped:

$$
T e_k \;=\; \lambda_k e_k, \qquad
\sum_{k=1}^{\infty} |\lambda_k| \;<\; \infty,
 \qquad \lVert T \rVert_{\mathrm{tr}} = \sum_{k} |\lambda_k|.
$$

去掉条件后结论不再成立。

Used together with: [[Ch07-S04-H02-B03 - Example 7.4.2c|Example 7.4.2c]], [[Ch09-S01-H01-B03 - Estimate 9.1.1c|Estimate 9.1.1c]].
