# Orthogonal Projection Identity 7.4.3d

**正交投影恒等式 7.4.3d** · identity · 7.4.3d

⬆️ Part of [[Ch07-S04-H03 - Basic Properties Orthogonal Projection|Basic Properties: Orthogonal Projection]] · [[Ch07-S04-H03 - Basic Properties Orthogonal Projection|正交投影：基本性质]]

The pairing is computed in coordinates, which gives the identity we quote later:

$$
\langle x, y \rangle \;=\; \sum_{i=1}^{n} x_i \overline{y_i}
 \;=\; \lVert P_{M} x \rVert^{2} + \lVert P_{M^{\perp}} x \rVert^{2}.
$$

恒等式在正交投影的讨论中反复使用。
