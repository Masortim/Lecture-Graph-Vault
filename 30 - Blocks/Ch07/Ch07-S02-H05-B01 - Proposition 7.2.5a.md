# Feature Map Proposition 7.2.5a

**特征映射命题 7.2.5a** · statement · 7.2.5a

⬆️ Part of [[Ch07-S02-H05 - Main Theorem Feature Map|Main Theorem: Feature Map]] · [[Ch07-S02-H05 - Main Theorem Feature Map|特征映射：主定理]]

For every $x \in X$ the quantity below is finite and controls the rest of the section:

$$
\lVert Tx \rVert \;\le\; L\,\lVert x \rVert_{X}, \qquad L = \sup_{\lVert x \rVert_{X}=1} \lVert Tx \rVert_{Y}.
$$

该命题是本节后续结果的出发点。
