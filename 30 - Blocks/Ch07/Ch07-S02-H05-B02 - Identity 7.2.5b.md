# Feature Map Identity 7.2.5b

**特征映射恒等式 7.2.5b** · identity · 7.2.5b

⬆️ Part of [[Ch07-S02-H05 - Main Theorem Feature Map|Main Theorem: Feature Map]] · [[Ch07-S02-H05 - Main Theorem Feature Map|特征映射：主定理]]

The pairing is computed in coordinates, which gives the identity we quote later:

$$
\langle x, y \rangle \;=\; \sum_{i=1}^{n} x_i \overline{y_i}
 \;=\; \lVert P_{M} x \rVert^{2} + \lVert P_{M^{\perp}} x \rVert^{2}.
$$

恒等式在正交投影的讨论中反复使用。
