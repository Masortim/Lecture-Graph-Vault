# Feature Map Example 7.2.5d

**特征映射例子 7.2.5d** · example · 7.2.5d

⬆️ Part of [[Ch07-S02-H05 - Main Theorem Feature Map|Main Theorem: Feature Map]] · [[Ch07-S02-H05 - Main Theorem Feature Map|特征映射：主定理]]

The model case below shows that the hypothesis cannot be dropped:

$$
T e_k \;=\; \lambda_k e_k, \qquad
\sum_{k=1}^{\infty} |\lambda_k| \;<\; \infty,
 \qquad \lVert T \rVert_{\mathrm{tr}} = \sum_{k} |\lambda_k|.
$$

去掉条件后结论不再成立。
