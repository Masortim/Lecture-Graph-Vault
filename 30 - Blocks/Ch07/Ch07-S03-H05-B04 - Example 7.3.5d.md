# Vector Space Example 7.3.5d

**向量空间例子 7.3.5d** · example · 7.3.5d

⬆️ Part of [[Ch07-S03-H05 - Main Theorem Vector Space|Main Theorem: Vector Space]] · [[Ch07-S03-H05 - Main Theorem Vector Space|向量空间：主定理]]

The model case below shows that the hypothesis cannot be dropped:

$$
T e_k \;=\; \lambda_k e_k, \qquad
\sum_{k=1}^{\infty} |\lambda_k| \;<\; \infty,
 \qquad \lVert T \rVert_{\mathrm{tr}} = \sum_{k} |\lambda_k|.
$$

去掉条件后结论不再成立。
