# Feature Map Estimate 7.2.5c

**特征映射估计 7.2.5c** · estimate · 7.2.5c

⬆️ Part of [[Ch07-S02-H05 - Main Theorem Feature Map|Main Theorem: Feature Map]] · [[Ch07-S02-H05 - Main Theorem Feature Map|特征映射：主定理]]

A standard symmetrisation argument yields the quantitative bound:

$$
\mathbb{P}\bigl\{\,|f(X)-\mathbb{E}f| \ge t\,\bigr\}
 \;\le\; 2\exp\!\left(-\frac{2nt^{2}}{(b-a)^{2}}\right),
 \qquad t>0.
$$

此估计决定了样本复杂度的阶。
