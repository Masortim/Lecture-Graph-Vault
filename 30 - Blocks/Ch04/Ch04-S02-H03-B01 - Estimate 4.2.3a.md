# Vector Space Estimate 4.2.3a

**向量空间估计 4.2.3a** · estimate · 4.2.3a

⬆️ Part of [[Ch04-S02-H03 - Basic Properties Vector Space|Basic Properties: Vector Space]] · [[Ch04-S02-H03 - Basic Properties Vector Space|向量空间：基本性质]]

A standard symmetrisation argument yields the quantitative bound:

$$
\mathbb{P}\bigl\{\,|f(X)-\mathbb{E}f| \ge t\,\bigr\}
 \;\le\; 2\exp\!\left(-\frac{2nt^{2}}{(b-a)^{2}}\right),
 \qquad t>0.
$$

此估计决定了样本复杂度的阶。
