# Kernel Matrix Example 4.1.4a

**核矩阵例子 4.1.4a** · example · 4.1.4a

⬆️ Part of [[Ch04-S01-H04 - Key Lemma Kernel Matrix|Key Lemma: Kernel Matrix]] · [[Ch04-S01-H04 - Key Lemma Kernel Matrix|核矩阵：关键引理]]

The model case below shows that the hypothesis cannot be dropped:

$$
T e_k \;=\; \lambda_k e_k, \qquad
\sum_{k=1}^{\infty} |\lambda_k| \;<\; \infty,
 \qquad \lVert T \rVert_{\mathrm{tr}} = \sum_{k} |\lambda_k|.
$$

去掉条件后结论不再成立。
