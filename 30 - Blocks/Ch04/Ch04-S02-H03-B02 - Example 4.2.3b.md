# Vector Space Example 4.2.3b

**向量空间例子 4.2.3b** · example · 4.2.3b

⬆️ Part of [[Ch04-S02-H03 - Basic Properties Vector Space|Basic Properties: Vector Space]] · [[Ch04-S02-H03 - Basic Properties Vector Space|向量空间：基本性质]]

The model case below shows that the hypothesis cannot be dropped:

$$
T e_k \;=\; \lambda_k e_k, \qquad
\sum_{k=1}^{\infty} |\lambda_k| \;<\; \infty,
 \qquad \lVert T \rVert_{\mathrm{tr}} = \sum_{k} |\lambda_k|.
$$

去掉条件后结论不再成立。
