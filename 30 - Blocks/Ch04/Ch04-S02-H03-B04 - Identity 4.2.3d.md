# Vector Space Identity 4.2.3d

**向量空间恒等式 4.2.3d** · identity · 4.2.3d

⬆️ Part of [[Ch04-S02-H03 - Basic Properties Vector Space|Basic Properties: Vector Space]] · [[Ch04-S02-H03 - Basic Properties Vector Space|向量空间：基本性质]]

The pairing is computed in coordinates, which gives the identity we quote later:

$$
\langle x, y \rangle \;=\; \sum_{i=1}^{n} x_i \overline{y_i}
 \;=\; \lVert P_{M} x \rVert^{2} + \lVert P_{M^{\perp}} x \rVert^{2}.
$$

恒等式在正交投影的讨论中反复使用。
