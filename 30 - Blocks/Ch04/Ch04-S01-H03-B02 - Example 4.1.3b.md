# Feature Map Example 4.1.3b

**特征映射例子 4.1.3b** · example · 4.1.3b

⬆️ Part of [[Ch04-S01-H03 - Basic Properties Feature Map|Basic Properties: Feature Map]] · [[Ch04-S01-H03 - Basic Properties Feature Map|特征映射：基本性质]]

The model case below shows that the hypothesis cannot be dropped:

$$
T e_k \;=\; \lambda_k e_k, \qquad
\sum_{k=1}^{\infty} |\lambda_k| \;<\; \infty,
 \qquad \lVert T \rVert_{\mathrm{tr}} = \sum_{k} |\lambda_k|.
$$

去掉条件后结论不再成立。
