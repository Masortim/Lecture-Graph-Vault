# Kernel Matrix Proposition 4.1.4b

**核矩阵命题 4.1.4b** · statement · 4.1.4b

⬆️ Part of [[Ch04-S01-H04 - Key Lemma Kernel Matrix|Key Lemma: Kernel Matrix]] · [[Ch04-S01-H04 - Key Lemma Kernel Matrix|核矩阵：关键引理]]

For every $x \in X$ the quantity below is finite and controls the rest of the section:

$$
\lVert Tx \rVert \;\le\; L\,\lVert x \rVert_{X}, \qquad L = \sup_{\lVert x \rVert_{X}=1} \lVert Tx \rVert_{Y}.
$$

该命题是本节后续结果的出发点。
