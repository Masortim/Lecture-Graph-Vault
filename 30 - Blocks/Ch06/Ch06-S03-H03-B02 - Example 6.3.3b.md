# Weak Convergence Example 6.3.3b

**弱收敛例子 6.3.3b** · example · 6.3.3b

⬆️ Part of [[Ch06-S03-H03 - Basic Properties Weak Convergence|Basic Properties: Weak Convergence]] · [[Ch06-S03-H03 - Basic Properties Weak Convergence|弱收敛：基本性质]]

The model case below shows that the hypothesis cannot be dropped:

$$
T e_k \;=\; \lambda_k e_k, \qquad
\sum_{k=1}^{\infty} |\lambda_k| \;<\; \infty,
 \qquad \lVert T \rVert_{\mathrm{tr}} = \sum_{k} |\lambda_k|.
$$

去掉条件后结论不再成立。

Used together with: [[Ch04-S02-H04-B02 - Proposition 4.2.4b|Proposition 4.2.4b]], [[Ch05-S03-H03-B02 - Example 5.3.3b|Example 5.3.3b]].
