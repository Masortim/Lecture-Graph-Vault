# Compact Set Example 6.1.3b

**紧集例子 6.1.3b** · example · 6.1.3b

⬆️ Part of [[Ch06-S01-H03 - Basic Properties Compact Set|Basic Properties: Compact Set]] · [[Ch06-S01-H03 - Basic Properties Compact Set|紧集：基本性质]]

The model case below shows that the hypothesis cannot be dropped:

$$
T e_k \;=\; \lambda_k e_k, \qquad
\sum_{k=1}^{\infty} |\lambda_k| \;<\; \infty,
 \qquad \lVert T \rVert_{\mathrm{tr}} = \sum_{k} |\lambda_k|.
$$

去掉条件后结论不再成立。
