# Compact Set Example 1.1.3b

**紧集例子 1.1.3b** · example · 1.1.3b

⬆️ Part of [[Ch01-S01-H03 - Basic Properties Compact Set|Basic Properties: Compact Set]] · [[Ch01-S01-H03 - Basic Properties Compact Set|紧集：基本性质]]

The model case below shows that the hypothesis cannot be dropped:

$$
T e_k \;=\; \lambda_k e_k, \qquad
\sum_{k=1}^{\infty} |\lambda_k| \;<\; \infty,
 \qquad \lVert T \rVert_{\mathrm{tr}} = \sum_{k} |\lambda_k|.
$$

去掉条件后结论不再成立。

Used together with: [[Ch01-S04-H02-B03 - Example 1.4.2c|Example 1.4.2c]], [[Ch03-S01-H01-B03 - Estimate 3.1.1c|Estimate 3.1.1c]].
