# Compact Set Identity 1.1.3d

**紧集恒等式 1.1.3d** · identity · 1.1.3d

⬆️ Part of [[Ch01-S01-H03 - Basic Properties Compact Set|Basic Properties: Compact Set]] · [[Ch01-S01-H03 - Basic Properties Compact Set|紧集：基本性质]]

The pairing is computed in coordinates, which gives the identity we quote later:

$$
\langle x, y \rangle \;=\; \sum_{i=1}^{n} x_i \overline{y_i}
 \;=\; \lVert P_{M} x \rVert^{2} + \lVert P_{M^{\perp}} x \rVert^{2}.
$$

恒等式在正交投影的讨论中反复使用。
