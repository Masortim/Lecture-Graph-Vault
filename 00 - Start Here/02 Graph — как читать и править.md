# Два графа в одном хранилище

## A. Встроенный Graph view (`Ctrl+P → Graph view: Open graph`)

Уже настроен в `.obsidian/graph.json`: **сначала девять цветов по главам** (глава и всё, что
внутри неё, — одним цветом; группы построены по `path:`, поэтому работают без плагинов), а
«остальным» — цвета по уровням (главы — янтарные, секции — синие, заголовки — зелёные,
блоки — сиреневые), стрелки направления ссылок, скрытие «сирот» и папок со служебным
(`40 - Templates`, `45 - Captions`, `35 - Abstracts`, `50 - Dashboard`, `00 - Start Here`,
`60 - Drawings`, `90 - Exports`). Ограничение честное: встроенный граф Obsidian рисует узлы на canvas,
поэтому **размер узла по числу ссылок и двухстрочные подписи там недоступны** —
там есть только общий ползунок `Node size` и подпись = имя файла.

## B. Lecture Graph (свой плагин, `.obsidian/plugins/lecture-graph`)

Вершины = заметки с `type:` (главы/секции/заголовки/блоки + опционально инлайн-блоки `^якорь`).

### Размер вершины = число входящих ссылок

```
r = minR + (maxR − minR) · clamp((deg − base) / (refMax − base), 0, 1)^γ
```

* `deg` — сколько раз на вершину сослались (по умолчанию считаются только текстовые ссылки;
  переключатель `Vertex size =` добавляет структурные `Part of…` и врезки `![[…]]`). У блока
  с ключевыми фразами на месте `deg` стоит **вес по корпусу** — число вхождений фраз из
  `keywords_en:` (см. §7 заметки [[01 Conventions — правила разметки]]);
* `refMax` — «потолок», относительно которого измеряется: **гибрид** (по умолчанию) — сглаженная
  смесь максимума по своему уровню и по всему графу, `только по уровню`, `только по всему графу`
  (выбор `Относительно чего` в панели инструментов и в настройках);
* `base` — ноль шкалы: минимальная степень в графе (по умолчанию) или ноль ссылок (`Ноль шкалы размеров`);
* `γ = 0.55` — степень масштабирования (чем меньше, тем контрастнее).

Поэтому **каждый уровень заметно разного размера**, а не одинакового: у глав в демо-каркасе
13–48 (5 разных значений) входящих ссылок → радиусы 17–29, у секций 21–70 (19 разных значений) → 19–33, у заголовков
9–81 (46 разных значений) → 13–34, у блоков 2–69 (11 разных значений) → 6–32 (общий диапазон 6–34 px).
Ссылки есть не только на блоки: в секциях под последним заголовком стоит «лестница» ссылок
на главы, соседние секции, заголовки и блоки — именно она и даёт верхним уровням разный размер.
Размер можно поправить и вручную — свойством `size:` в заметке вершины (`1.4` — множитель,
`22px` — фиксированный радиус): см. §«Размер, цвет и сообщение задаются в свойствах заметки».

### Ключевые фразы: связи из корпуса, а не из текста

`Ctrl+P → Lecture Graph: Recompute keyword links` ищет фразы из `keywords_en:` по аннотациям
`35 - Abstracts` и дописывает найденное в заметку блока отдельным блоком между маркерами
`keywords:begin/end` — граф строится по этим ссылкам как по любым другим, так что никаких
«своих» рёбер у плагина нет. На холсте это видно сразу: у блока появляются дуги к заголовкам
и секциям других глав (мосты между кластерами), он растёт в размерах по числу вхождений, а его
цвет может уехать в главу-лидер; в легенде тогда появляется сноска «N вершин окрашены главой,
собравшей больше вхождений их ключевых фраз». Клик по такому блоку показывает в пузырьке сам
список фраз, его вес и главу-лидер.

Тумблер `Считать рёбра по ключевым фразам` (в настройках, по умолчанию включён) отключает и рёбра,
и вес: картинка остаётся ровно такой, как на ручных ссылках. Папка корпуса — `Папка аннотаций
(корпус для фраз)`, по умолчанию `35 - Abstracts`; её держат исключённой из обхода, иначе
аннотации стали бы вершинами.

### Подписи: две строки, кегль ∝ размеру вершины, наездов нет

* Основная строка — `name` (English), вторая — `name_zh` (翻译). Правятся двойным кликом по вершине
  (модалка пишет значения в frontmatter, тело и `$$формулы$$` не трогаются), либо через
  `Ctrl+P → Lecture Graph: Edit label of current note`, ПКМ по вершине, или меню файла.
* `A−` / `A+` в панели инструментов (и команды `Decrease/Increase label font size`) меняют кегль
  **в полтора раза заметнее прежнего**: это множитель `Масштаб подписей` с шагом ×1.15, текущее
  значение и кегль в пикселях видны рядом с кнопками. Галочка `кегль ∝ размеру вершины` включает
  привязку: `font = (labelFontMin + (labelFontMax − labelFontMin) · frac) · labelScale`, то есть у
  вершины с 69 ссылками подпись крупнее, чем у блока с 2. Галочку можно снять — тогда весь текст
  одним кеглем (`Базовый кегль`).
* Режим показа: `по размеру вершины` (по умолчанию), `всегда`, `при наведении`, `не показывать`.
  Порог «по размеру» — это **квантиль шкалы** `minRadius…maxRadius`, а не фиксированное число
  пикселей: сдвиньте ползунок `Max radius` — и набор подписанных вершин останется тем же, подписи
  не исчезают (раньше на крупном радиусе они пропадали целиком).
* **Кегль на экране не зависит от масштаба графа.** Весь курс (1000+ вершин) после `⤢ Fit` живёт
  на масштабе ≈7 %, и если бы подпись уменьшалась вместе с ним, она превращалась бы в 0.8 px —
  в серую пыль. Поэтому текст рисуется ровно `n.font` пикселями на экране при ЛЮБОМ отдалении,
  а при приближении (масштаб больше 100 %) начинает расти вместе с картинкой. Круги вершин тоже
  не вырождаются в точки: у них есть минимум 2.2 px на экране, а толщина дуг вообще задана
  в экранных пикселях (`vector-effect: non-scaling-stroke`).
* Места на экране не резинового размера, поэтому при отдалении подписей видно **столько, сколько влезло**
  (десятки крупных меток вместо сотен нечитаемых). Они расставляются жадно по приоритету:
  выбранная и наведённая вершина, затем главы → секции → заголовки → блоки, внутри уровня —
  крупные раньше мелких; кто не влез, тот не рисуется вовсе, поэтому **наездов нет ни на одном
  масштабе**. Приближайтесь `+` или колесом — подписей становится больше.
* **Подписи не наезжают друг на друга — ни в модели, ни на экране.** В модели (её видит экспорт SVG)
  вершины после раскладки расталкиваются вместе со своими метками (`packLabels`), а внутри кластера —
  ещё и по стенкам своего сектора, поэтому размещаются все подписи, которые режим показывает; на экране
  к этому добавляется расстановка из предыдущего пункта. Длинные названия обрезаются по ширине,
  отведённой packing'ом (`…` на конце); обрезается только рисунок — `name` в свойствах заметки
  остаётся полным. Наведённая или выбранная вершина показывается **целиком**: она и так рисуется
  поверх остальных.

### Управление видом

| что | как |
|---|---|
| во весь экран | кнопка `⛶ Full screen` в панели инструментов, `Shift`/`Ctrl`+клик по иконке на ленте, команда `Open graph view (full screen)`; выход — `Esc` или та же кнопка |
| клик по главе или секции | три вещи сразу: вершина и её соседи подсвечиваются (остальные приглушаются), **все её рёбра перерисовываются акцентным цветом** отдельным толстым слоем, и рядом с ней открывается пузырёк с сообщением |
| сообщение у вершины | скруглённая рамка **рядом с вершиной** — она не закрывает ни сам круг, ни его подпись. Текст живёт не в свойствах вершины, а в отдельной заметке (`45 - Captions/<id> — caption.md`), на которую указывает `caption:`; правится там же, как текстовый прямоугольник на слайде. Работает для вершин всех четырёх типов; у каждого типа свой шаблон (`40 - Templates/T Caption Chapter.md`, `T Caption Section.md`, `T Caption Heading.md`, `T Caption Block.md`) |
| создать сообщение | в пузырьке у вершины без `caption:` есть кнопка «+ Создать по шаблону»: она заводит заметку в `45 - Captions` и сама дописывает `caption:` в свойства вершины (тело заметки и формулы не трогаются) |
| `✎ править текст` | открывает заметку сообщения в редакторе; `Ctrl+P → Lecture Graph: Edit caption of current note` — то же из любой открытой заметки |
| снять выделение / скрыть сообщение | второй клик по той же вершине, `✕` в пузырьке, клик по фону сцены или `Esc` |
| граф на полном экране | кнопка `⛶` (или `⛶ во весь экран`), команда `Open graph view (full screen)`, `Shift`+клик по иконке на ленте. В этом окне не остаётся **ничего, кроме графа**: панель инструментов, легенда и подсказки скрыты; `Esc` — выйти |
| цвета | легенда под тулбаром показывает цвета глав (клик по чипу оставляет на экране только эту главу, повторный клик — вернуть все); строка состояния Obsidian для счётчиков не используется: `loading…`, счётчики после фильтров и ошибки живут тостом сверху холста и сами убираются |
| перестроить | `⟳ Rebuild` / команда `Rebuild graph now` (с `Shift` — заново разложить) |
| пересадить | `✎ Layout` |
| физика | `▶ Physics` / `⏸ Physics off`; расталкивание кругов включено всегда, `polish` добивает наложения в конце |
| зум | кнопки **`+` и `−` в правом нижнем углу холста** (они же команды `Zoom graph in`/`Zoom graph out`, они же клавиши `+` и `−`); рядом — текущий масштаб в процентах, а кнопка `⤢` вписывает граф в окно. Кнопки висят на холсте, а не в панели, поэтому работают и на полном экране |
| панорама | колесо (зум к курсору), тащить фон мышью; `⤢ Fit` — вписать в окно |
| фильтры | чипы типов, `min degree`, глава, поиск по EN/中文/`id` |
| экспорт | `⤓ JSON` — граф целиком (`lecture-graph-<дата>.json` в `90 - Exports/`), `Export current graph as SVG`, `Export labels + reference counts (CSV)`, `Save labels table as a note` → тоже в `90 - Exports/` |
| подсказка по жестам | одна строка при наведении на панель инструментов (постоянной строки подсказок нет) |
| иерархическое оглавление (с цветными полосками по уровням) | правый клик по папке в «Проводнике» → `Создать оглавление курса` (по заметке → `Обновить …`), либо `Ctrl+P → Lecture Graph: Regenerate course index (hierarchical TOC note)` → [[Course Index]]; путь правится в настройках («Файл иерархического оглавления»), оглавление в граф не входит |

`name` — как в свойствах заметки, `label_en`/`label_zh` — как реально нарисовано (обрезка по ширине),

отдать d3/ Gephy / own-скрипту и получить ровно ту картинку, что видите вы. Экспортируется **только
видимое** (после фильтров), как и SVG.

### Раскладка: чем раскладываем граф, и что при этом гарантировано

Движок раскладки выбирается в панели графа (группа `Раскладка`) и в настройках (`Чем раскладывать`);
по умолчанию включён `fdp`. Пять режимов:

| режим | как считает | что видно |
|---|---|---|
| `fdp` | пружинный оптимизатор в духе fdp из Graphviz: отталкивание всех со всеми + пружины по рёбрам, шаг уменьшается по «температуре», сверху — стягивание к центру своей главы | обычная «пружинная» картинка: плотные пятна глав, равные длины связей |
| `neato` | стресс-мажоризация: градиентный прогрев, затем шаги, которые выравнивают фактические расстояния с желаемой длиной связи | расстояния между концами связи ближе всего к `Длина связи`, граф шире и «жёстче» |
| `twopi` | радиальные слои: радиус вершины = глубина в дереве от корня (`Корень для twopi`), угол = клин поддерева, размер клина — по числу листьев | видна иерархия `глава → секция → заголовок → блок` концентрическими кольцами |
| `clusters` | детерминированная упаковка: каждой главе — свой угловой сектор, внутри сектора — кольца по уровням | **структурные рёбра не пересекаются**; этим режимом сделаны эталонные PNG/SVG |
| `force` | «живая» физика: пружины + отталкивание, вершины можно таскать мышью | интерактивный режим; чистота меток доводится пост-обработкой при остановке цикла |

Режима «кольца по уровням» (`radial`), который был в прошлых поставках, больше нет: то же самое
умеет делать `twopi`, но с корнем, который можно задать, и с гарантированно чистыми метками.

Общий финал для всех режимов (это и есть причина, почему картинка не «плывёт»):

* после движка результат проходит пост-обработку «расходиться»: сначала весь граф один раз
  масштабируется так, чтобы «пятаки» вершин (круг + подпись) влезли в полосу по ширине (множитель
  конечен — `layout.spreadMax`, по умолчанию 12: без потолка на редком виде с крупными подписями
  холст раздувался бы в десятки раз, и `Fit` показывал точки с микроскопическим текстом), затем метки упаковываются в горизонтальные полосы, а круги
  расталкиваются. Сдвиг каждой вершины
  ограничен `Предельным сдвигом при разведении`; если чистоты достичь не удалось, шаг
  повторяется на подросшем (×1.18) холсте — последняя ступень без лимита, потому что «чисто на
  экране» важнее, чем «пиксель в пиксель как положил алгоритм»;
* поэтому **наложений кругов и подписей нет ни в одном режиме** — в том числе после перетаскивания
  вершины, после правки `size:` и после смены кегля подписей;
* раскладка считается целиком и синхронно (тот же код, что в CLI и в превью), а не «на середине
  анимации»: переключили режим — получили финальную картинку;
* пересечения рёбер гарантированы только в `clusters`. Пружинные движки оптимизируют расстояния, а
  не планарность: на этом курсе (1017 вершин, 6061 ребро) пар пересечений структуры — 0 в
  `clusters`, 105 в `twopi`, 4282 в `neato`, 11698 в `fdp`. Если вам нужна диаграмма «без
  скрещиваний» — это `clusters`;
* движки написаны на JS в `src/graph-core.js` (не Graphviz и не wasm): fdp ≈ 2 с, neato ≈ 3 с,
  twopi ≈ 0.5 с на полном графе, и в плагин не приходится тащить несколько мегабайт;
* рёбра — дуги (`Кривизна рёбер`, по умолчанию `0.24`; `0` — прямые). Структурные дуги ведутся
  «веером» вокруг центра, ссылки на тексты изгибаются от центра графа;
* круги вершин не накладываются друг на друга (расталкивание с запасом под подпись).

Настройки движков — там же, в `Раскладка`: `Итераций fdp`, `Итераций neato`, `Шаг слоя twopi`,
`Корень для twopi`, `Стягивание по главам` (0 — главы расползаются, больше — плотные пятна),
`Расходиться подписями`, `Расходиться кругами`, `Предельный сдвиг при разведении`, а также
`Длина связи`, `Отталкивание`, `Притяжение к центру` и `Радиус колец` для `clusters`/`force`.

Проверить глазами и цифрами: `node dev/render_previews.js` кладёт `90 - Exports/graph-<режим>.svg`
и `graph-overview-<режим>.svg` (крупный план глав и секций) для каждого движка, `node dev/probe_modes.js` печатает время, размер, число наложений и пересечений
структуры по всем режимам, `node dev/diag_graph.js --mode fdp` — то же для одного режима (с
проверкой инвариантов).

### Размер, цвет и сообщение задаются в свойствах заметки

| поле | эффект на графе |
|---|---|
| `size: 1.4` / `size: 22px` | множитель радиуса (или фиксированный радиус) — **кегль подписи меняется вместе с ним**, поэтому крупная вершина не остаётся с мелким текстом |
| `color: "#ff7a6b"` | цвет вершины вместо цвета своей главы (наследование: секции, заголовки и блоки берут цвет главы; выключается настройкой `Цвет по главам`) |
| `caption: "[[Ch01 — caption]]"` | текст сообщения, который покажется пузырьком при клике |
| `keywords_en: "duality gap"` | связи блока с секциями и заголовками курса по аннотациям `35 - Abstracts`: найденное материализуется в ссылки (команда `Recompute keyword links`), а число вхождений задаёт размер вершины вместо ссылочной степени (§7 в [[01 Conventions — правила разметки]]) |
| `weight: 9` | вес по корпусу, который посчитал алгоритм; руками не заполняется — нужен дашбордам и CSV |

`size:` и `color:` применяются сразу (кнопка `⟳` не нужна): плагин пересчитывает размеры, кегли и
пересобирает упаковку, так что подписи не начинают наезжать друг на друга после правки.

## Почему оглавления [[Course Index]] в графе нет

Оглавление — указатель, а не раздел курса, поэтому оно не участвует ни в плагине, ни во
встроенном Graph View. Для плагина достаточно того, что `Course Index.md` лежит **в корне
хранилища**: обходятся только папки курса из `Folders to scan` (`10 - Chapters,20 - Sections,
25 - Headings,30 - Blocks`), так что вершиной заметка стать не может — ни при каких настройках
сканирования, ни если создать её правым кликом в другой папке (там её отсекает `type: index`,
которого нет среди четырёх типов вершин). Во встроенном графе все папки со служебным видны,
поэтому там её держит за скобками `-tag:#index`.

Заметка при этом покрывает весь курс: её 1017 ссылок ведут на каждую вершину (проверить
покрытие можно командой `Rebuild graph now` — вершин и в оглавлении, и в графе должно быть
одинаковое число).

### Создать или обновить из проводника

Плагин добавляет в контекстное меню «Проводника» (правый клик) пункт **«Создать оглавление
курса»**:

| клик по | что получится |
| --- | --- |
| папке (в корне хранилища — правым кликом по пустому месту под списком) | `<папка>/Course Index.md`; клик по пустому месту даёт ровно `Course Index.md` в корне — то место, где оглавление лежит в поставке. Нет файла — создастся, есть — перезапишется (пункт подписан «Обновить оглавление курса») |
| любой md-заметке | то же, но в папке этой заметки |
| самой заметке оглавления | обновится она сама, дубль рядом не появится |

Ничего не чинится «на глаз»: файл пишет `core.toIndexMarkdown` — ровно та же функция, что и у
команды палитры `Regenerate course index`, поэтому оглавление из меню и из команды совпадают
до байта (кроме метки пересборки в последней строке). `Folders to scan` и `excludeFolders` при
этом не меняются, папки создаются сами, а заметка получает `type: index`, `tags: [index]` и
`cssclasses: ["lg-index"]` — то есть остаётся указателем вне графа, где бы она ни лежала
(во встроенном графе её держит за скобками `-tag:#index`).

Ссылки оглавления мешают только одному — счётчикам «на вершину ссылаются». Их видит Dataview,
поэтому запросы [[Graph Board]] и [[Label Board]] вычитают ссылки, пришедшие из
её путь `Course Index.md`: тогда «ссылок на неё» на доске = `refs` во frontmatter =
то, из чего плагин считает размер вершины, а таблица «сироты» не пустеет. Разметку самих
заметок это не касается: в текстах по-прежнему считается только то, что написано под
заголовками.

## Как добавить вершину в граф

1. Создайте заметку шаблоном из `40 - Templates` (Templater сам спросит коды и обе подписи).
2. Впишите текст и формулы.
3. Поставьте на неё ссылку из текста секции — всё, `Rebuild` и вершина появится; радиус
   пересчитается по числу входящих ссылок.

## Если что-то не так

| симптом | причина / что сделать |
|---|---|
| вершин нет | у заметок нет `type:` в frontmatter, или папка не входит в `Folders to scan` |
| много «unresolved» в счётчиках (тост сверху холста сразу после `⟳ Rebuild`) | ссылка ведёт на имя, которого нет: напишите полное имя файла (`[[Ch01-S03-H06-B03 - Example 1.3.6c|…]]`) — `[[id]]` работает только через алиасы |
| формула показывает `$$` текстом | вокруг `$$` нет пустых строк, или блок обёрнут в callout/список — см. [[01 Conventions — правила разметки]] |
| подпись не обновилась | `⟳ Rebuild` (или `Ctrl+P → Lecture Graph: Rebuild graph now`) |
| граф «взрывается» при открытии | включите `Раскладка → Кластеры глав` (там нет физики, результат детерминированный), увеличьте `Радиус колец`, уменьшите `Отталкивание`; затем `⏸ Physics` |
| подписи наехали друг на друга | `⟳ Rebuild` — он пересобирает упаковку меток; при ручной расстановке (`✎ Layout`) расталкивание меток не применяется |
| пузырёк лёг на вершину | так не должно быть: рамка ставится справа от круга, а если не влезает — слева (`placeBubble`). Помогает `⤢ Fit` или меньший `Max radius` |
| сообщение не показывается | пузырёк всегда открывается при клике по вершине любого типа; если заметки сообщения нет, в нём есть кнопка «+ Создать по шаблону» — она заводит `<id> — caption.md` и дописывает `caption:` в свойства вершины |
| вершин очень много и тормозит | ограничьте `Folders to scan`, поднимите `Min degree`, поднимите `Лимит узлов` только если он режет |
